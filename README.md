# Adakami Help Center

Landing page pusat bantuan Adakami untuk mengarahkan pengunjung ke kanal dukungan WhatsApp.

## Pengembangan

```bash
npm install
npm run dev
```

## Pemeriksaan

```bash
npm test
npm run build
```

Nomor dan pesan WhatsApp dapat dikonfigurasi melalui `VITE_SUPPORT_NUMBER` dan `VITE_SUPPORT_MESSAGE`.
